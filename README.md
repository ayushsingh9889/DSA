## 🥞 Stack Implementation

A menu-driven Stack implementation in Java with the following operations:

- Push — Add an element to the stack
- Pop — Remove the top element
- Peek — View the top element
- Display — Display all stack elements
- Status — Check whether the stack is empty or full
- Stack Info — Display stack information
- Multiple Push — Add multiple elements
- Multiple Pop — Remove multiple elements
- Exit — Exit the program
